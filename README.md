# Full Stack Lab Exercises

This repository contains college lab submissions for a basic full stack web development assignment.

## Contents

- `Lab_2_Responsive_Website` - responsive education management pages using HTML, Tailwind CSS, Font Awesome, and canvas.
- `Lab_3_Form` - semantic student registration form with JavaScript form output.
- `Lab_4_Course_Explorer` - course explorer using JSON data, Fetch API, and a service worker.
- `Lab_5_React_ProfileCard` - React profile card starter component.

## Running The Labs

Labs 2 and 3 can be opened directly in a browser.

For Lab 4, use a local server such as VS Code Live Server because it uses `fetch()` and a service worker.

For Lab 5, create a Vite React app and copy `Lab_5_React_ProfileCard/App.jsx` into the generated `src/App.jsx`, then run:

```bash
npm install
npm run dev
```
